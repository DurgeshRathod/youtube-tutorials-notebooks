## Scene 7: Vector Similarity - Distance (43-50 seconds)

## Scene 8: Vector Similarity - Cosine (50-56 seconds)
**Visual:** Highlight angles between vectors

```
Cosine Similarity - direction-based measure!

Formula: cos(θ) = (A·B) / (||A|| * ||B||)
Range: -1 to +1

Cosine(A, B) = 0.998 → almost same direction
Cosine(A, C) = 0.889 → different angle

Recommendation systems use this!
Word embeddings similarity - Word2Vec, BERT!
Angle matters, not magnitude!
```

## Scene 11: Technical Deep Dive (68-75 seconds)
**Visual:** Show mathematical formulas and complexity

```
Vector operations - computational perspective:

Dot Product: O(n) complexity
A·B = Σ(ai * bi)
Used in: Similarity, projections, neural network forward pass

Distance Computation:
Euclidean: O(n)
Manhattan: O(n) - |x1-x2| + |y1-y2|
Minkowski: O(n) - generalization

Optimization tip:
NumPy vectorization >> Python loops
GPU acceleration for large-scale vector ops!
```
